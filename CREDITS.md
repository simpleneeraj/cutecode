# Credits

CuteCode is built on the shoulders of an incredible open-source ecosystem. Thank you to
every project and team below. 💛

## Origin & inspiration

- **[ray.so](https://ray.so) & [Raycast](https://raycast.com)** — CuteCode began as a fork of
  the ray.so project. Huge thanks for the foundation and their commitment to open source.
- The code-screenshot space pioneered by **[Carbon](https://carbon.now.sh)** and
  **[Chalk.ist](https://chalk.ist)**.

## Core framework

- **[Next.js](https://nextjs.org)** — App Router, Server Components, the whole runtime.
- **[React](https://react.dev)** — UI library.
- **[TypeScript](https://www.typescriptlang.org)** — language & types.

## UI & styling

- **[Tailwind CSS](https://tailwindcss.com)** — utility-first styling.
- **[Base UI](https://base-ui.com)** + **[coss](https://coss.com/ui)** — accessible component primitives.
- **[Radix UI](https://www.radix-ui.com)** — additional primitives.
- **[vaul](https://vaul.emilkowal.ski)** — drawer component.
- **[Motion](https://motion.dev)** — animations.
- **[Lucide](https://lucide.dev)** & **[Iconify](https://iconify.design)** — icons.
- **[Solar Icon Set](https://www.figma.com/community/file/1166831539721848736)** by 480 Design
  (CC BY 4.0) — icon system.
- Fonts: **[Plus Jakarta Sans](https://github.com/tokotype/PlusJakartaSans)** and
  **[Geist Mono](https://vercel.com/font)**.

## Code rendering

- **[Shiki](https://shiki.style)** — syntax highlighting (TextMate-grade, 100+ languages).
- **[html-to-image](https://github.com/bubkoo/html-to-image)** — DOM → PNG export.

## Data, auth & API

- **[Supabase](https://supabase.com)** — authentication (`@supabase/ssr`, `supabase-js`).
- **[Prisma](https://www.prisma.io)** — ORM (`@prisma/client`, `@prisma/adapter-pg`).
- **[PostgreSQL](https://www.postgresql.org)** — database.
- **[tRPC](https://trpc.io)** — end-to-end typesafe API.
- **[Zod](https://zod.dev)** — schema validation.
- **[Jotai](https://jotai.org)** — state management.
- **[SWR](https://swr.vercel.app)** — data fetching.

## Payments, infra & ops

- **[Dodo Payments](https://dodopayments.com)** — subscriptions & billing.
- **[Dub](https://dub.co)** — short links.
- **[Vercel](https://vercel.com)** — hosting, OG image generation (`@vercel/og`), analytics.
- **[Pino](https://getpino.io)** — logging.

excellent libraries.
